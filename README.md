# 🎰 Premium Sports Hub

Модерна платформа за спортни залози и казино игри, построена с React.

## 🚀 Функционалности

- ⚽ **Спортни залози** - Многообразие от спортни събития с живи коефициенти
- 🎰 **Казино игри** - Различни казино игри включително слотове, рулетка, блекджек и др.
- 👤 **Профил** - Управление на профила, депозити и теглене
- 💬 **Живо чат поддържка** - 24/7 помощ
- 📱 **Отзивчив дизайн** - Работи на всички устройства
- 🎨 **Модерен интерфейс** - Привлекателен и лесен за използване

## 🛠️ Технологии

- **React** - JavaScript библиотека
- **React Router** - Маршрутизация
- **CSS3** - Стилизация с градиенти и анимации

## 📦 Инсталация

```bash
# Клониране на репозиторий
git clone https://github.com/ivanovtodor565-bot/premium-sports-hub.git
cd premium-sports-hub

# Инсталирай зависимостите
npm install

# Стартирай сървъра за разработка
npm start
```

## 🌐 Отваряне

Сайтът ще се отвори на http://localhost:3000

## 📋 Начало

1. **Регистрирай се или влез** с тестови потребител
2. **Избери спорт** или казино игра
3. **Постави залог** с твоята стратегия
4. **Наслади се** на опита
